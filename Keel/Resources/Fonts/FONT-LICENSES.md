# Bundled fonts

All fonts here ship under the **SIL Open Font License 1.1** (OFL), which permits
bundling inside an application at no cost. Downloaded from Google Fonts.

| File | Family | Designer / source | Licence |
|---|---|---|---|
| `Literata.ttf` | Literata (variable) | TypeTogether (Google) | OFL 1.1 |
| `Poppins-Light.ttf` `Poppins-Regular.ttf` `Poppins-Medium.ttf` | Poppins | Indian Type Foundry, Jonny Pinhorn | OFL 1.1 |
| `TwemojiMozilla.ttf` | Twemoji Mozilla (COLR emoji) | Mozilla / Twitter | CC-BY 4.0 |

The OFL requires the licence text to accompany distribution and forbids selling
the fonts on their own; bundling them inside the app is fine. Full licence text:
<https://openfontlicense.org>. Registered in `Config/Info.plist` under
`UIAppFonts` and used via `KeelFont` (see `DESIGN_PRINCIPLES.md` §5).
